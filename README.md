# YASHIRIN.UZ starter website

## Files
- `index.html` — responsive starter website (HTML, CSS and JavaScript)
- `logo.png` — replace this placeholder with your actual logo (keep the filename `logo.png`)

## Publish with GitHub Pages
1. Create a **public** repository named `yashirin-uz`.
2. Upload `index.html` and `logo.png` to the repository root.
3. Click **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then **Save**.
6. Wait a few minutes and open the URL shown in the Pages settings.

## Before launch
This is a starter demo, not a fully verified travel guide. Check all destination information, image rights, transport/access, safety and contact details before promoting it. Replace the sample contact email with an address you control. The language toggle switches the included text between Uzbek and English.
